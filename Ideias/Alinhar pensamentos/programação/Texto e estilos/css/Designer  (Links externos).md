## Fontes
[Flyerwiz](https://flyerwiz.app/font-pairing-generator/) principal modelo de fonte, veja cards para comparar modelos Harmônicos, além disso tem: [paleta de cores](https://flyerwiz.app/color-palettes/) e [controle de brilho](https://flyerwiz.app/color-contrast-checker/) com legibilidade, ou seja se o ícone, fontes pequenas estão legíveis(referente a paleta de cores, [faça aqui](https://flyerwiz.app/color-palatte-generator/)), Principal.

- inspiração

	- [Typewolf](https://www.typewolf.com/) Fontes seus modelos e sugestões de uso, Fraco. 
	- [Envato](https://elements.envato.com/pt-br/fonts) para ver exemplos e modelos em uso, Médio.
	- [Cssfontstack](https://www.cssfontstack.com/) Porcentagem de uso de cada estilo em diferentes projetos, pesquisas gerais de css (cor, converter formatos, fav icon.. ), Médio.
	-  [Fontspace](https://www.fontspace.com/) Fontes seus modelos e sugestões de uso, Forte. 

-  Fontes Harmônicas
	- [Monotype](https://www.monotype.com/font-pairing#/explore) veja combinações de fontes, Fraco.

- Modelos de Fontes
	- [Fontsquirrel](https://www.fontsquirrel.com/fonts/list/hot) veja qual é a fonte e ache modelos para uso e principais em uso, Médio
	- [Fontes do google](https://fonts.google.com/) para importações diretas no projeto, Forte

### Gradient e Palette
 - [Css gradient ](https://cssgradient.io/) Gere gradient, Fraco.
 - [Coolors](https://coolors.co/) Faça os elos perdidos das cores, intervalo entre cores e modelos de paletas, Média.
 - [ColorSpace](https://mycolor.space/?hex=%23845EC2&sub=1) Gere uma palheta de cores de acordo com uma cor, diversas cores que combinam com a selecionada, Média
 - [flyerwiz](https://flyerwiz.app/color-palatte-generator/) Gere famílias das cores
 - [Color Designer](https://colordesigner.io/) Tem diversas tools de cores, além do gradient, como paletas, comparações, Forte


### Grid
- [Grid Container](https://origamid.com/projetos/css-grid-layout-guia-completo/) Veja mais detalhes de como se comporta diferentes elementos do grid, para [visualizar](https://origamid.com/projetos/grid/).

- [Layoutit](https://grid.layoutit.com/) Faça a construção do seu grid de forma simple, defina div com nomenclaturas corretas e uma melhor Indentação (Tem modelos simples de uso para construção de uma [prototipagem](https://layoutit.com/build)).

- [CSS Grid Generator](https://cssgrid-generator.netlify.app/)   Modelo simple de criação grid.

- [Guia de Grid](https://css-tricks.com/snippets/css/complete-guide-grid/) Um guia das tags usada en grid, além de outros, como flexbox.


### Flexbox
- [ CSS Flex Container](https://cssflex-generator.netlify.app/) Modelo simple de criação Flexbox

- [Css Generator](https://cssgenerator.pl/en/flexbox-generator/) Criação de flexbox, botão, shadown...
