### Definição classe abstrata

Uma classe abstrata é uma propriedade da orientação a objetos que permite definir um padrão ou template para as classes filhas. Normalmente, em uma classe abstrata, é comum declarar um método abstrato, ou seja, um método apenas com assinatura, sem implementação.

Uma classe abstrata não pode ser instanciada diretamente. Ela serve como base para outras classes que a herdam e implementam os métodos abstratos definidos. Dessa forma, a classe abstrata fornece um modelo genérico que pode ser compartilhado por um grupo de classes derivadas.

## Sobreposição 5
![[Pasted image 20241001105525.png]]
Sobreposição é a propriedade de POO, que permite que o método da classe pai seja redefinido na classe filha, devendo possuir a mesma assinatura (tipo de retorno, void, int.. nome do método e parâmetros).

## Sobrecarga 6
![[Pasted image 20241001110314.png]]
Sobrecarga é a propriedade de POO, que permite o método de uma determinada classe seja redefinido diversas vezes, devendo possuir assinaturas diferentes
